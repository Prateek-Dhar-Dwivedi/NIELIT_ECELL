# N.E.X.T. - NIELIT E-Cell

Welcome to the official repository for **N.E.X.T.** (NIELIT Entrepreneurship eXperience & Transformation), the student-driven entrepreneurship ecosystem for NIELIT. 

This platform serves as the primary gateway to highlight our vision, activities, impact, and to bring together students who are passionate about ideas, innovation, and entrepreneurship.

## Tech Stack
- **Frontend Framework:** React.js
- **Animations:** Framer Motion
- **Styling:** Custom CSS with modern layouts (Flexbox, Grid) and responsive media queries
- **Bootstrapped with:** Create React App

## Features
- **Responsive Layout:** Fully optimized for desktops, tablets, and small mobile screens.
- **Modern UI/UX:** Clean typography, layout symmetry, and fluid entrance animations.
- **Sectioned Navigation:** Smooth scrolling to various parts of the platform including Home, About, Vision, What We Do, Impact, Events, Team, Gallery, and Contact.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have Node.js installed on your machine. You can download it from [nodejs.org](https://nodejs.org/).

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/Prateek-Dhar-Dwivedi/NIELIT_ECELL.git
   ```
2. Navigate to the project directory:
   ```sh
   cd next-ecell
   ```
3. Install NPM packages:
   ```sh
   npm install
   ```

### Running the App

To start the development server, run:
```sh
npm start
```
Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will hot-reload whenever you make changes.

## Building for Production

To create an optimized production build, run:
```sh
npm run build
```
This builds the app for production to the `build` folder. It correctly bundles React in production mode and optimizes the build for the best performance. Your app is then ready to be deployed.
